# LINE Seed JP

Copyright 2020–2022 LY Corporation.

The Regular and Bold WOFF2 files are unmodified official LINE Seed JP fonts, released under the SIL Open Font License 1.1. The full license and original copyright notice are included in [OFL.txt](./OFL.txt).

- Official site and licensing: https://seed.line.me/index_jp.html
- Download: https://seed.line.me/src/images/fonts/LINE_Seed_JP.zip
- Upstream archive directory: `LINESeedJP_20241105/Web/WOFF2/`
- `LINESeedJP_OTF_Rg.woff2` → `LINESeedJP-Regular.woff2`
- `LINESeedJP_OTF_Bd.woff2` → `LINESeedJP-Bold.woff2`

Only the filenames have been changed; font contents are unchanged. These fonts are bundled locally so the UI does not contact a third-party font service. Both proportional text and code use LINE Seed JP as requested; code is not rendered in a monospace font. Glyphs not provided by LINE Seed JP (for example emoji) fall back to the browser's system fonts.
